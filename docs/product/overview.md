# 使用 LayerScape

## 产品介绍

打开图纸，自动替换缺失字体。

AFR 自动识别并替换图纸中的缺失字体，减少文字缺失和乱码。从默认字体设置到替换结果复核，都在熟悉的 AutoCAD 中完成。

LayerScape（叠境）为 AutoCAD 提供实用工具。本指南介绍缺失字体自动替换（AFR）的安装、配置和日常使用。

## 从打开图纸，到核对文字

收到外部图纸、设置常用字体、检查替换结果：按你正在做的事，找到对应操作。

| 使用场景 | 如何处理 | 入口 |
| --- | --- | --- |
| 收到图纸，发现缺失字体 | 打开图纸时，AFR 自动识别并替换缺失字体，支持 SHX 主字体、大字体、TrueType 和多行文字内联字体。 | [了解自动替换](modules.md) |
| 想用自己常用的替换字体 | 输入 AFR，为三类字体选择默认替换目标。之后的缺失字体处理按你的配置进行。 | [设置替换字体](../../README.md#首次配置与验证) |
| 替换之后，还想检查一下 | 输入 AFRLOG 查看替换记录，对当前图纸逐项调整或批量填充。检查显示效果后再保存图纸。 | [查看替换结果](../../README.md#手动替换) |

## 三步开始使用

先安装到需要使用的 CAD，再设置替换字体，最后打开图纸检查显示效果。

| 步骤 | 操作 | 入口 |
| --- | --- | --- |
| 下载并安装 | 关闭 AutoCAD，运行部署工具，选择要安装的 CAD 版本。 | [安装指南](../../README.md#快速开始) |
| 选择替换字体 | 在 AutoCAD 中输入 AFR，设置 SHX 主字体、大字体和 TrueType 字体。 | [字体配置](../../README.md#首次配置与验证) |
| 检查图纸显示 | 打开图纸后检查文字，用 AFRLOG 查看记录并按需要调整。 | [查看替换结果](../../README.md#手动替换) |

## 缺失字体，自动处理

打开含有缺失字体的图纸时，AFR 会识别并替换缺失字体。你可以设置默认替换目标，也可以在替换日志中逐项检查和调整。

了解[字体替换功能](modules.md)，或直接查看[配置与使用](../../README.md#首次配置与验证)。如果替换后文字显示异常，先不要保存图纸，请按[常见问题](../../README.md#afr-常见问题)中的说明处理。
