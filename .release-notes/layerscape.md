## 概述

本次发布延续 LayerScape 面向 AutoCAD 的统一安装与管理方式，重点覆盖发布交付改进、安装说明完善与若干使用相关修复。

## 更新内容

变更包括：新增“通过置顶 Issue 请求仓库配置”；修复发布流程以按产品配置发布 GitHub 附件并兼容既有更新器；更新窗口与插件日志中的项目地址；并同步更新发行说明与贡献指引相关文档。

## 兼容性

产品文档给出的兼容范围为 AutoCAD 2018–2027（对应 .NET Framework 4.6.2/4.7.2/4.8、.NET 8.0、.NET 10.0），后续功能默认沿用同一适配与安装方式。

除上述文档声明外，当前资料未提供本次发布独立的兼容性复验结果。

## 升级与迁移

从 9.x 迁移时，文档建议先备份 DLL、字体与 FixedProfile.aws 及相关注册表项，再安装新版本；迁移前不建议先卸载旧配置，以避免插件配置被清除。

## 安装说明

推荐下载并运行 AFR-Deployer_v${version}.exe 进行安装；发布渠道为 GitHub Releases，并提供 AFR-DLL_v${version}.zip 与 Fonts.zip。部署器会扫描本机 AutoCAD 版本并完成 DLL 部署、自动加载项写入及默认字体释放。

## 已知问题

已知限制：单 DLL 手动 NETLOAD 场景不支持自动抑制“缺少 SHX 文件”弹窗；若图纸正文字符已被错误编码保存，字体替换无法恢复原文。

## 恢复

如需回退，先关闭 AutoCAD，使用部署器卸载当前安装，再恢复备份的 DLL、字体、FixedProfile.aws 与对应注册表项，并核对 LOADER 指向原 DLL 后用图纸副本复验。
