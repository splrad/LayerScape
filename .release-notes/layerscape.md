## 概述

LayerScape v1.0.1 本次以问题修复和发布交付整理为主，包含“按产品配置发布 GitHub 附件并兼容既有更新器”，同时补充了面向下载者的发行说明与产品用途文档。

## 更新内容

已记录的变更还包括：将 Pages 控制器引用纳入 Renovate 更新、更新窗口与插件日志中的项目地址，以及多项构建/依赖维护更新（如 actions/setup-dotnet 6.0.0→6.1.0、dotnet-sdk 10.0.402→11.0.100 等）。这些维护项主要用于仓库与交付流程治理，未在资料中声明直接功能增量。

## 兼容性

兼容范围沿用既有基线：AutoCAD 2018–2027；对应运行环境为 .NET Framework 4.6.2 / 4.7.2 / 4.8 及 .NET 8.0 / 10.0（按 AutoCAD 年份分配）。

## 升级与迁移

从 9.x 迁移建议先备份 DLL、Fonts、自定义配置与相关注册表项，再在原部署路径安装新系列；不建议为迁移先执行卸载，以免清除插件配置。迁移后应逐个 AutoCAD 版本用图纸副本核对加载、AFR 设置、AFRLOG 与显示结果。

## 安装说明

推荐安装方式仍为运行 AFR-Deployer_v${version}.exe：先关闭所有 AutoCAD，再执行部署器完成版本扫描、安装/卸载与自动加载项写入。手动场景可下载 AFR-DLL_v${version}.zip 并按 AutoCAD 年份选择 DLL 进行 NETLOAD；Fonts.zip 仅在需要单独获取字体时使用。

## 已知问题

已知限制：单 DLL 手动 NETLOAD 不支持自动抑制 AutoCAD“缺少 SHX 文件”弹窗；AFRUNLOAD 为维护入口，需完整输入命令名；若图纸文字数据已错误编码保存，字体替换无法恢复原文。

## 恢复

如需回退或撤销迁移：先关闭 AutoCAD，用部署器卸载当前安装，再恢复已备份的 DLL、字体、FixedProfile.aws 与对应注册表项，并核对 LOADER 指向原 DLL，最后使用图纸副本复验。GitHub Releases 实际附件是否已齐全需以发布页当时状态为准，本文未验证。
