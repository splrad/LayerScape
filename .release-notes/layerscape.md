## 概述

本次发布包含一项新增功能与多项发布流程相关修复：新增了“通过置顶 Issue 请求仓库配置”，并调整了 release 附件发布方式以按产品配置分发，同时兼容既有更新器。

## 更新内容

面向使用者可见的变化主要包括：发布附件策略已按产品配置整理并保持与既有更新器兼容；项目地址文案（窗口与插件日志）已更新；发行说明改为面向下载者的用途表达。其余大量变更属于 Actions/依赖/模板维护更新。

## 兼容性

兼容范围保持为 AutoCAD 2018–2027。对应运行环境为：2018 使用 .NET Framework 4.6.2，2019–2020 使用 .NET Framework 4.7.2，2021–2024 使用 .NET Framework 4.8，2025–2026 使用 .NET 8.0，2027 使用 .NET 10.0。

## 升级与迁移

升级时建议优先使用部署器执行覆盖安装，不要先卸载再迁移。对于历史 9.x 用户，资料明确旧 9.x 部署器不会提示降版到 1.0.0，需从 Releases 手动获取公开安装包；本次发布还包含“兼容既有更新器”的发布侧修复。

## 安装说明

推荐安装方式仍为运行 AFR-Deployer_v${version}.exe（GitHub Releases 渠道提供）；手动方式可下载 AFR-DLL_v${version}.zip 后按 AutoCAD 年份选择 DLL 并通过 NETLOAD 加载。字体单独包 Fonts.zip 可按需下载，部署器已包含默认字体。

## 已知问题

当前提供资料未单列本版本新增已知问题清单；因此无法确认是否存在未披露的特定已知问题，相关风险状态未验证。

## 恢复

如需回退/恢复，先关闭 AutoCAD，再卸载本次安装并恢复你自己的 DLL、字体与 FixedProfile.aws 备份，随后导入对应注册表备份并核对 LOADER 指向原 DLL；仅恢复对应宿主和原部署路径，并用图纸副本复验。
