## 概述

本次发布延续 LayerScape 面向 AutoCAD 2018–2027 的统一安装与管理方式，并新增了“通过置顶 Issue 请求仓库配置”的入口，方便使用者按仓库配置需求提交请求。

## 更新内容

本次用户相关变更包括：1) release 流程已按产品配置发布 GitHub 附件并声明兼容既有更新器；2) 更新了窗口和插件日志中的项目地址；3) 与发布说明相关文档已调整为面向下载者和产品用途的表达。

## 兼容性

兼容范围保持为 AutoCAD 2018–2027；对应运行环境为 .NET Framework 4.6.2 / 4.7.2 / 4.8，以及 .NET 8.0 / 10.0（按 AutoCAD 年份对应）。

## 升级与迁移

升级前请先关闭所有 AutoCAD 进程。推荐直接运行 `AFR-Deployer_vX.Y.Z.exe` 覆盖安装；文档中未要求先卸载后再装。关于“兼容既有更新器”的实际升级链路表现，当前资料未提供独立验证结果。

## 安装说明

安装渠道为 GitHub Releases。推荐下载并运行 `AFR-Deployer_v${version}.exe` 进行安装与管理；手动场景可使用 `AFR-DLL_v${version}.zip` 通过 `NETLOAD` 加载；仅需字体时可下载 `Fonts.zip`。

## 已知问题

已知限制：单 DLL 手动 `NETLOAD` 不支持自动抑制 AutoCAD“缺少 SHX 文件”弹窗；MText 内联字体采用运行时映射自动处理，不支持手动替换；若图纸正文字符已错误编码保存（文字数据已损坏），字体替换无法恢复原文。

## 恢复

如替换后文字显示异常，请不要保存图纸，先用 `AFRLOG` 重新选择替换字体并复核显示；需要卸载时，部署工具场景可在 `AFR-Deployer` 中执行“卸载”，单 DLL 场景需在命令行完整输入 `AFRUNLOAD`。
